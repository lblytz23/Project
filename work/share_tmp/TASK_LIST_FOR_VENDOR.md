> **项目名称**: 标注数据质量检查系统

> **创建日期**: 2025-12-08

---

## 一、项目背景

本项目包含4个 Python 脚本，用于对机器学习标注数据进行质量检查。现需对这些脚本进行优化和功能完善。

### 1.1 脚本清单

| 脚本名称 | 功能说明 |
|---------|---------|
| `file_related.py` | 扫描数据目录，提取文件元数据并存入 SQLite 数据库 |
| `file_related_process.py` | 从数据库读取数据，执行规则检查，输出问题清单 |
| `image_related_process_for_anoti.py` | 检测相似/重复图片（pHash + ORB 算法） |
| `image_load_check.py` | 检测损坏/无法加载的图片 |

### 1.2 数据流关系
```
file_related.py  ──►  camera_file_summary.db  ──►  file_related_process.py  ──►  ng_list.csv

image_related_process_for_anoti.py  ──►  similar_images.csv / similar_images.html

image_load_check.py  ──►  corruption_detection_results.csv
```
